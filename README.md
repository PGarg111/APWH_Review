# APWH_Review
I made a website which helps anyone taking the AP World History exam study and prepare for the exam. This website includes breakdowns, SAQ, MCQ, and SPICE-T information for each sub unit. For each unit there are videos as well as LEQ and DBQ practice. For the LEQ, DBQ, and SAQ there is any option to have AI (Gemini) grade the user's responses and give them real time feedback. The website also has flashcards for each unit which are the key terms for each sub unit. Even though I haven't added anything to the exam prep tab yet, when the user hovers on the nav bar it gives them text taking strategies for the exam and motivational messages. 

This website uses mostly JavaScript and CSS with minimal HTML. Because of the amount of content needed to upload into this website, I couldn't use HTML to input it. JS allowed me to create a frame for the information and then for each section add it and display it to the user without having to multiply it for everything. I recently learned Java so I already had an idea of how to create the JS. For the rest I learned how to integrate JS into HTML in a website like this through AI. I used Gemini to teach me how to create the frame and went from there.

I created this website because when I took the AP World exam, there were many things that no one told me that I wish I knew before taking the test. A lot of the practice I had was either given by the teacher or on College Board. Practice outside of this didn't really apply to the test very much because it either didn't go in depth like the College Board questions did or wasn't free to use. I did use the information from the AMSCO textbook, but this website gives the user an explanation for why it was wrong/right and feedback on the written portions of the exam. 

Portions of the Website with Information:
 - All the units have LEQ and DBQ prompts added with space to plan for both of the essays
 - Unit 1 has Heimler Videos added
 - Unit 1.1, 3.1 have breakdowns, MCQ, and SAQ added
 - Unit 1.1 has the SPICE-T themes added
 - Unit 1.1 and 3.1 flashcards are added in Flashcards in their respective unit sections (unit 3.1 doesn't have the definitions for most of them)
